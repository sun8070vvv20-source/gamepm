## 3. F2P (Free-to-Play) 모델

### 3-1. IAP (인앱 결제) 설계

장르 결정 후 해당 시 상세화.

| 유형 | 설명 | 윤리적 고려 |
|------|------|-----------|
| **코스메틱** | 외형 아이템 (게임플레이 무영향) | 안전 |
| **편의 (Convenience)** | 시간 단축, 인벤토리 확장 | 주의 — Pay-to-Win 경계 |
| **콘텐츠 해금** | 추가 스테이지, 캐릭터 | 안전 (실질적 DLC) |
| **가챠/루트박스** | 확률 기반 아이템 | 위험 — 규제 대상 다수 국가 |
| **배틀패스** | 시즌 기반 보상 체계 | 중간 — FOMO 활용 |

**원칙**:
- Pay-to-Win 금지
- 모든 게임플레이 핵심 콘텐츠는 무료로 접근 가능
- 확률형 아이템은 확률 공개 필수

### 3-2. 광고 설계

| 유형 | 노출 시점 | 사용자 경험 영향 | 수익성 |
|------|----------|----------------|--------|
| 보상형 광고 | 플레이어 선택 시 | 낮음 (자발적) | 중간 |
| 배너 광고 | 메뉴/로비 | 중간 | 낮음 |
| 전면 광고 | 스테이지 전환 | 높음 | 중-높음 |
| 네이티브 광고 | 게임 내 자연스러운 배치 | 낮음 | 낮음 |

**원칙**:
- 게임플레이 중 강제 광고 금지
- 보상형 광고 우선 (플레이어 선택권 존중)
- 광고 빈도 상한 설정 (세션당 N회)

## 9. 수익 모델 결정 가이드

장르·플랫폼이 결정되면 아래 흐름으로 수익 모델을 선택한다.

```
[장르 확정]
    │
    ├─ 단일 플레이 경험 중심 (스토리, 퍼즐, 어드벤처)
    │       → 프리미엄 (유료 판매)
    │       → 선택: + DLC (추가 콘텐츠)
    │
    ├─ 반복 플레이 중심 (로그라이크, 액션, 시뮬)
    │       → 프리미엄 or F2P + 코스메틱 IAP
    │       → 선택: + 배틀패스 (시즌 콘텐츠)
    │
    ├─ 캐주얼/하이퍼캐주얼
    │       → F2P + 보상형 광고
    │       → 선택: + 광고 제거 IAP
    │
    └─ 라이브 서비스/멀티플레이어
            → F2P + IAP (코스메틱)
            → 선택: + 배틀패스 + 시즌 콘텐츠
```
