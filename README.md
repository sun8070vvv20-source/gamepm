| 루트 · 커버 | 지원서 PDF 다운로드 ↓ / 웹으로 보기 ↗ | `지원서_박세훈.pdf` · `application/` |
| 루트 · 커버 | 포트폴리오 PDF 다운로드 ↓ / 웹으로 보기 ↗ | `portfolio/portfolio.pdf` · `portfolio/` |

## 6. PDF 재생성

| 문서 | 뽑을 파일 | 용지 | 상태 |
|---|---|---|---|
| 지원서 | `application/index.html` | **A3 portrait · 여백 0** (CSS `@page`에 박혀 있음) | 정상. 배경 그래픽 켬, 배율 83% 권장 |
| 포트폴리오 | `portfolio/index.html` | — | **아래 제약 확인 필요** |

지원서는 아래처럼 다시 뽑습니다. 배율은 `05.작업_관리/자소서_작업규칙.json`을 따릅니다.

```bash
python -m http.server 8899 --bind 127.0.0.1
```

```bash
chrome --headless=new --disable-gpu --no-pdf-header-footer --virtual-time-budget=15000 --print-to-pdf="out.pdf" "http://127.0.0.1:8899/application/"
```

루트 `index.html`은 화면용이라 인쇄에 쓰지 않습니다.

> **신규 포트폴리오에는 인쇄용 스타일이 없습니다.** `@media print`·`@page` 규칙이 0건이라,
> 그대로 인쇄하면 좌측 300px 사이드바와 1440px 고정 그리드가 그대로 찍힙니다.
> 또 React가 화면을 그린 뒤에야 본문이 생기므로 headless 인쇄 시 `--virtual-time-budget`을
> 넉넉히(20000 이상) 줘야 빈 페이지가 나오지 않습니다.
> PDF를 다시 만들려면 인쇄용 스타일을 새로 넣거나, 기존 `portfolio.pdf`를 그대로 두고
> 웹 버전만 최신으로 쓰는 쪽을 택해야 합니다.

## 7. Vercel 배포

1. GitHub에 새 저장소를 만들고 **이 폴더 안의 내용물을 저장소 최상단에** 넣습니다.
   `.gitignore`가 백업 폴더를 알아서 걸러냅니다.
2. [vercel.com](https://vercel.com) → **Add New → Project** → 해당 저장소 선택
3. 설정은 건드리지 않습니다. 정적 파일이라 빌드가 필요 없습니다.

   | 항목 | 값 |
   |---|---|
   | Framework Preset | Other |
   | Build Command | 비움 |
   | Output Directory | 비움 |
   | Install Command | 비움 |

4. **Deploy**를 누릅니다.

배포 후 주소는 두 종류가 나옵니다. 배포별 주소(`프로젝트-해시-계정.vercel.app`)는 매번 바뀌므로,
상단 **Domains**에 표시되는 프로덕션 주소(`프로젝트명.vercel.app`)를 쓰세요.

**배포 직후 아래 두 주소를 직접 열어 404가 나는지 확인하세요.**
한글 경로라 `.vercelignore` 규칙이 안 먹을 가능성을 배제할 수 없습니다.

```
https://내주소/README.md
https://내주소/01.사업 PM 참고자료/
```

**직무별로 저장소를 나누세요.** 한 저장소에 여러 직무 버전을 넣으면 채용 담당자가 다른 직무 지원서를 보게 됩니다.

| 버전 | 저장소 예시 | 주소 예시 |
|---|---|---|
| 게임 사업 PM | `parksehoon-pm` | `parksehoon-pm.vercel.app` |
| 게임 기획 | `parksehoon-game` | `parksehoon-game.vercel.app` |
| 웹·앱 기획 | `parksehoon-web` | `parksehoon.vercel.app` |

다시 올릴 때는 `git add . && git commit && git push`. 프로덕션 주소는 그대로이고 내용만 갱신됩니다.

본문 전체가 `<x-dc>` 템플릿이라 React 로드에 실패하면 아무것도 렌더되지 않습니다.
면접관이 사내망이나 오프라인에서 열 가능성이 있다면 PDF 링크를 주 동선으로 두는 편이 안전합니다.

**루트에 증명사진이 base64로 들어 있습니다.** 별도 이미지 파일 없이 단일 HTML로 동작해 656KB입니다.

**루트는 스크롤에 맞춰 요소가 나타납니다.** 커버 배경의 느린 그라데이션 표류, 좌우에서 모여드는 본문 2단,
제목 밑줄 훑기, 도구 칩 순차 등장, 타임라인 세로선 그리기 등의 모션이 얹혀 있습니다.
`prefers-reduced-motion`과 인쇄에서는 전부 정지하고 최종 상태로 고정됩니다.
자바스크립트가 막힌 환경에서는 `<noscript>` 규칙이 적용돼 모든 내용이 처음부터 보입니다.

**폰트는 외부에서 받아옵니다.** Pretendard와 IBM Plex Mono를 CDN에서 불러오며,
인터넷이 끊기면 시스템 기본 글꼴로 대체됩니다. 레이아웃은 유지됩니다.
