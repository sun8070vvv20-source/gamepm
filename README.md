# 게임 사업 PM 지원 · 배포 폴더

지원서와 포트폴리오를 **한 저장소, 한 배포**로 올립니다.
페이지 간 링크가 모두 상대 경로라 도메인이 바뀌어도 끊기지 않습니다.

**루트(`index.html`)가 곧 지원서입니다.** 들어오면 바로 지원 동기부터 경력기술서까지 읽히고,
포트폴리오와 인쇄본 PDF는 그 안의 버튼으로 이어집니다.

- 대상 직무: 게임 사업 PM (사업 관리 · 라이브 옵스 · 이벤트 운영)
- 개편 기준: 2026-08-11 (웹·앱 기획 버전을 PM 관점으로 전면 재작성)
- 경력 표기: 기획 실무 4년 5개월 (이노디스, 그라비티 네오싸이언, 이노컴즈)

## 1. 폴더 구조

이 폴더의 내용물이 그대로 사이트 루트가 됩니다.

```

├── 지원서_박세훈.pdf                 지원서 인쇄본 (1.03MB · A3 2페이지)
├── application/
│   ├── index.html                  지원서 A3 레이아웃 (23KB)
│   └── photo.jpg                   증명사진 (168KB)
├── portfolio/
│   ├── index.html                  포트폴리오 (83KB)
│   ├── portfolio.pdf               포트폴리오 인쇄본 (6.2MB · A4 14페이지)
│   └── images/                     실무 산출물 3장 + 화면 캡처 + 도구 아이콘 (22MB)
```

업로드 대상 합계는 약 30MB입니다. 대부분이 `portfolio/images/`(22MB)와 포트폴리오 PDF(6.2MB)입니다.

## 6. PDF 재생성

두 PDF는 HTML의 인쇄용 스타일(`@media print`)을 그대로 출력한 것입니다.

| 문서 | 뽑을 파일 | 용지(CSS `@page`) | 설정 |
|---|---|---|---|
| 지원서 | `application/index.html` | **A3 portrait · 여백 0** | 배경 그래픽 켬. 배율은 83% 권장(`05.작업_관리/자소서_작업규칙.json` 참조) |
| 포트폴리오 | `portfolio/index.html` | A4 portrait · 여백 14/15/13mm | 배경 그래픽 끔 |

루트 `index.html`은 화면용이라 인쇄에 쓰지 않습니다.

용지 규격은 각 HTML의 `@page` 규칙에 이미 박혀 있어, 브라우저 인쇄 대화상자에서 따로 지정하지 않아도 적용됩니다.
명령줄로 다시 뽑으려면 로컬 서버를 띄운 뒤 아래처럼 실행하면 됩니다.

```bash
python -m http.server 8899 --bind 127.0.0.1
```

```bash
chrome --headless=new --disable-gpu --no-pdf-header-footer --virtual-time-budget=15000 --print-to-pdf="out.pdf" "http://127.0.0.1:8899/application/"
```

## 7. Vercel 배포

1. GitHub에 새 저장소를 만들고 **이 폴더 안의 업로드 대상 5개**를 저장소 최상단에 넣습니다.
2. [vercel.com](https://vercel.com) → **Add New → Project** → 해당 저장소 선택
3. 설정은 건드리지 않습니다. 정적 파일이라 빌드가 필요 없습니다.

   | 항목 | 값 |
   |---|---|
   | Framework Preset | Other |
   | Build Command | 비움 |
   | Output Directory | 비움 |
   | Install Command | 비움 |

4. **Deploy**를 누릅니다.

배포 후 주소는 두 종류가 나옵니다. 배포별 주소(`프로젝트-해시-계정.vercel.app`)는 매번 바뀌므로, 상단 **Domains**에 표시되는 프로덕션 주소(`프로젝트명.vercel.app`)를 쓰세요.

**직무별로 저장소를 나누세요.** 한 저장소에 여러 직무 버전을 넣으면 채용 담당자가 다른 직무 지원서를 보게 됩니다.

| 버전 | 저장소 예시 | 주소 예시 |
|---|---|---|
| 게임 사업 PM | `parksehoon-pm` | `parksehoon-pm.vercel.app` |
| 게임 기획 | `parksehoon-game` | `parksehoon-game.vercel.app` |
| 웹·앱 기획 | `parksehoon-web` | `parksehoon.vercel.app` |

다시 올릴 때는 `git add . && git commit && git push`. 프로덕션 주소는 그대로이고 내용만 갱신됩니다.

## 9. 알아 둘 점

**루트에 증명사진이 base64로 들어 있습니다.** 별도 이미지 파일 없이 단일 HTML로 동작해 653KB입니다.

**루트와 포트폴리오는 스크롤에 맞춰 요소가 나타납니다.** 자바스크립트가 막힌 환경에서는 `<noscript>` 규칙이 적용돼 모든 내용이 처음부터 보입니다.

**폰트는 외부에서 받아옵니다.** Pretendard와 JetBrains Mono, IBM Plex Mono를 CDN에서 불러오며, 인터넷이 끊기면 시스템 기본 글꼴로 대체됩니다. 레이아웃은 유지됩니다.

**개편 전 원본은 `_backup_웹앱기획본_20260811/`에 있습니다.** 되돌리려면 그 안의 `index.html`, `portfolio/`, `README.md`, `지원서_웹앱기획자_박세훈.pdf`를 덮어쓰면 됩니다.
