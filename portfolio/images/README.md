03 자전거행복나눔은 개인정보처리시스템이라 캡쳐를 싣지 않습니다.
HTML 에서는 공백과 한글을 퍼센트 인코딩(`%20`, `%EA%B5%AD…`)해 참조하므로,
파일명을 바꾸면 `portfolio/index.html` 의 `src` 도 함께 고쳐야 합니다.

## 경력 (3장)

| 파일명 | 내용 |
|---|---|
| `work-screen.png` | 화면 설계서 · 환불계좌 등록 |

세 장은 클릭하면 원본이 새 창에서 열립니다. 목록에서는 4:3 상단 기준으로 잘라 높이를 맞춥니다.

## 도구 아이콘 (배치 완료)

`web/images/icons/` 에 figma, ppt, excel, hwp, vscode, claude, slack 7종이 들어 있습니다.
무채색 팔레트를 지키려고 CSS에서 회색조 필터를 적용합니다. 원본 파일은 그대로 두시면 됩니다.

## 권장 규격

| 항목 | 값 |
|---|---|
| 형식 | PNG 또는 WebP |
| 가로 폭 | 작업 방식 2200px 내외, 경력 1200px 내외 |
| 비율 | 가로형 권장 |
| 용량 | 파일당 500KB 이하 |
| 색상 | 사이트 UI는 무채색이지만 문서 캡처는 원본 색을 유지합니다 |

## 공개 전 확인

`work-` 로 시작하는 세 장은 실무 산출물입니다. 고객사명과 담당자명, 내부 시스템 주소가 보이지 않는 범위에서만 게재하시기 바랍니다.
